# 요구사항, 구현 범위, 남은 작업

## 기준

- Godot 엔진, 1인 주인공 싱글 플레이.
- 사용자가 제공한 림버스 컴퍼니 전투 영상 2개가 연출 기준.
- E.G.O와 랜덤 스킬 배정 제외. 독립적인 하단 전투 UI 사용.
- 스킬 모션·VFX 제작, 특히 애니메이팅 기능이 중요.
- 구현 → 실행 → 부족한 점 수정의 반복.

## 영상 분석과 추출

두 영상 길이는 약 31.73초 / 43.37초, 첫 영상 프레임 크기는 1112×512, 30fps입니다.
2초 간격 인덱스로 전체 흐름을 확인하고 주요 구간을 원본 크기로 추출했습니다.
프레임 단위로 전체 동작을 추적·복원한 상태는 아닙니다.

| 자산 | 개수 | 처리 | 한계 |
| --- | ---: | --- | --- |
| 주인공 포즈 | 3 | 수동 다각형 윤곽 + 투명 PNG | 자세별 원본 크기가 다름. 일부 배경/UI 경계 흔적 |
| 적 포즈 | 2 | 같은 방식 | 머리 위 부품과 실루엣 경계가 부정확할 수 있음 |
| 붉은 궤적 | 20샘플 | 첫 영상 색상 마스크 | 텍스트 일부와 캐릭터 붉은 부분이 섞일 수 있음 |
| 붉은 폭발 | 20샘플 | 둘째 영상 색상 마스크 | 같은 한계. 30fps 영상의 중복 샘플 포함 |
| 벽·바닥 | 2 | 가려지지 않은 부분 크롭 | 작은 패치를 반복해 3D 전장 재구성 |
| 상하 테두리 | 2 | 밝기 마스크 | 현재 게임 HUD에는 사용하지 않음 |
| 배경 보정 실험 | 1 | 크롭 + inpaint | 흐릿한 영역이 커서 게임에서는 사용하지 않음 |
| 전체 영상 인덱스 | 2 | 2초 간격 썸네일 | 분석용. 게임을 영상 재생으로 대체하지 않음 |

원본 영상의 SHA-256, 각 항목의 시각·좌표·마스크 종류는 `assets/extracted/manifest.json`에 있습니다.
게임 설치 파일을 분석하거나 원본 게임 패키지를 추출한 것이 아닙니다.
원본 레이어, 가려진 몸·포즈, 정확한 3D 맵, VFX 노드 구성, 분리된 음악·음성·타격음은 영상만으로 확보하지 못했습니다.

## 실제 게임화한 범위

`combat.gd`: 고정 3스킬, 적의 턴별 스킬, 확률 코인, 합 패배 시 코인 감소, 승자의 남은 코인 공격,
방어 피해 감소, 정신력 제한 ±45, 출혈 틱, 적 체력 절반에서 1회 흐트러짐, 승패/재시작.
타이 무한 반복을 피하기 위해 최대 64회 이후 속도로 결정합니다. 이는 원작 규칙을 검증한 값이 아닙니다.
속도는 표시와 타이 제한 처리에만 쓰며 다중 행동 순서·타깃 재지정에는 아직 쓰지 않습니다.

`game.gd`: 3D 바닥·벽·기둥, 투명 포즈 스프라이트, 접근/복귀, 카메라 줌/흔들림, 히트스톱,
추출 효과 시퀀스, 피해 숫자, 스킬 카드, 상태 표시, 자산 갤러리.
적 공격 모션은 대기 포즈 이동으로 대체하며 주인공 전용 피격 포즈는 아직 없습니다.
스킬별 코인 수와 효과는 다르지만 이동 패턴은 공통입니다.

`workshop.gd`: 기존 키/이벤트 편집기를 유지하면서 추출 PNG를 기본 포즈로 사용합니다.
`motion_clip.gd`: 저장한 JSON 모션을 검증·샘플링해 전투에 연결합니다.
전투에서 로드한 클립은 주인공의 코인별 시각 모션만 바꿉니다. 전투 피해는 모델에서 판정합니다.
편집기의 VFX 이벤트와 전투의 VFX 이벤트는 아직 통합되지 않았습니다.

## 다음 수정 우선순위

1. 원본과 같은 해상도를 얻으려면 영상 컷아웃을 교체할 원화가 필요합니다. 현재는 확대 시 흐림/픽셀 흔적이 있습니다.
2. 포즈 윤곽을 더 정밀하게 정리하고, UI가 없는 추가 포즈·피격·적 공격을 확보해야 합니다.
3. 효과에 남은 글자·붉은 캐릭터 픽셀을 수동 정리하고 가려진 부분을 직접 제작해야 합니다.
4. 한 스킬의 준비/이동/포즈 전환/타격/복귀를 원본 프레임과 나란히 비교해야 합니다.
5. 편집기의 고정 2.4초 길이, 실행 취소 부재, 키 드래그 부재, 트랙 분리 부재를 개선해야 합니다.
6. 전투의 코인별 재생을 전체 스킬 클립/다중 타격 이벤트 매핑으로 바꾸어야 합니다.
7. 피해 공식, 내성·공격/방어 레벨, 상태 효과 세부 규칙, 정신력 변화, 흐트러짐 수치는 원작 대조가 필요합니다.
8. 회피·반격, 여러 적, 부위, 타깃 선택, 속도별 행동 순서, 패시브와 세부 전투 UI는 미구현입니다.
9. 오디오와 게임패드, 창 크기별 UI, Windows 실기 실행은 추가 검증 대상입니다.

현재 결과는 영상 자산 일부를 사용하는 전투 프로토타입입니다. '모든 에셋 추출'이나 '원작과 동일한 완성도'로 판단할 수 없습니다.
